# AHORA

Quiero una web para mi asociación. Te adjunto el manual de estilo de la marca los logos y los estatutos la asociación para que sepas que poner en la web. 

Adicionalmente a lo que consideres, necesitamos un formulario de registro de socios, un blog de noticias y por ultimo un apartado de transparencias como los partidos políticos
